# EDIT

运行在 SB-DOS 下的文本编辑器，与 `ASM.EXE` 汇编器分别构建和运行。

## 构建

在 Windows 上使用 Node.js 22 及以上版本：

```powershell
npm install
npm run build
```

产物为 `build/sb2000/EDIT.EXE`。运行模拟器需要在 `fcdev.json` 中配置 BIOS 路径。

## 使用

在 SB-DOS 提示符下运行 `EDIT`。屏幕顶部是一行菜单栏（F1 文件、F5 汇编、F8 关于，右侧显示光标的行号与列号）。按 F1 弹出文件菜单，第一行显示文件名与保存状态，其下依次是打开文件、保存文件、汇编、关于、退出；按 F5 保存并调用 `ASM.EXE` 汇编；按 F8 查看软件简介。文件名遵循 DOS 8.3 格式。

编辑区支持文本的插入与删除、方向键移动，能显示 GB2312 汉字，也能用 DOS 的中文输入法输入汉字（Alt+F2 等切换输入法的按键与 DOS 下相同），光标与删除按字符处理。文档按 4 KiB 的扩展 RAM 页分块存放，不限制在 16 KiB 以内，最大约 480 KiB，还受 DOS 空闲页数限制。选择汇编前会先保存当前文件，`ASM.EXE` 需要和 `EDIT.EXE` 在同一张磁盘上。
