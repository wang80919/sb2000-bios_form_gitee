# EDIT 开发文档

`EDIT.EXE` 是运行在 SB-DOS 下的文本编辑器，用 fcdev 的 C（cc65）开发，与 `ASM.EXE` 汇编器各自独立构建、独立运行。使用方法见 [../README.md](../README.md)。

## 1. 功能

- 编辑文本：插入、删除、换行、方向键、Home、End、PgUp、PgDn、Ctrl+Home、Ctrl+End、Tab；GB2312 汉字可以显示，也可以用 DOS 的中文输入法输入，光标移动与删除按字符（汉字两个字节）处理。
- 文档按 4 KiB 的扩展 RAM 页分块存放，不限制在 16 KiB 以内。
- 顶部一行菜单栏，F1 弹出文件菜单：打开、保存、汇编、关于、退出；F5 保存并汇编；F8 显示关于。
- 命令行 `EDIT [文件名]`，给了文件名就直接打开。

## 2. 构建

```powershell
npm install
npm run build
```

产物为 `build/sb2000/EDIT.EXE`（32768 字节）。链接器的“Segment ‘BSS’ isn't aligned properly”警告是 fcdev 多页模板的已知现象，不影响运行。

## 3. 目录与库页

程序是多页程序：`$8000` 到 `$9FFF` 为常驻区，`$A000` 到 `$AFFF` 是库页窗口，同一时间只映射一个库页。`fcdev.json` 里 `banks` 为 5。

| 文件 | 库页 | 内容 |
| --- | --- | --- |
| `src/main.c` | 常驻 | 入口，取命令行第一个词作为要打开的文件 |
| `src/editor-state.h`、`src/editor.c`、`src/editor.h` | 3 | 文档状态与光标状态、光标移动、插入删除、按键分发、主循环 |
| `src/editor-commands.c`、`src/editor-commands.h` | 4 | F1 菜单、对话框、打开、保存、汇编、关于、退出 |
| `src/view.c`、`src/view.h` | 5 | 算出每行该显示的内容，与屏幕上已有的内容比较，只重画变化的部分 |
| `src/screen.c`、`src/screen.h` | 2 | 版面与绘制：菜单栏、编辑区、光标、弹出区 |
| `src/file-io.c`、`src/file-io.h` | 2 | 文件装入与保存，换行转换 |
| `src/text-buffer.c`、`src/text-buffer.h` | 1 | 分块文本缓冲 |

约定：

- 传给另一个库页的指针必须指向常驻区或全局缓冲，不能指向调用者所在库页里的数据。所以界面文字（GB2312 字节串）、路径缓冲和菜单显示缓冲都定义在 `SB_BANK_BEGIN` 之外。
- 状态变量（`document_path`、`uses_crlf`、`modified`、`editor_state`）放在常驻区，各库页都能读写。
- 新增代码后用 `build/obj/sb2000/edit/edit.map` 检查库页是否放得下。
- `src/main.c` 里的 `layout_padding` 是布局垫片：换页蹦床有一条 `jmp (target)`，间接跳转的地址不能落在页尾。常驻部分的长度变化后若链接报“jmp (abs) across page border”，把它的大小在 1 与 2 之间切换，并确认链接映射里 BSS 的起始地址是偶数。

## 4. 屏幕版面

屏幕是 32 × 30 个 8 × 8 的单元。文字是 8 × 16 的字模，一行文字占上下两个单元行，所以共 15 行文字，每行 31 列（第 0 列留空）。

| 单元行 | 区域 | 配色 |
| --- | --- | --- |
| 0、1 | 菜单栏：左侧 `F1文件  F5汇编  F8关于`，右侧 9 列显示光标位置“行:列”或一次性提示 | 白底黑字 |
| 2 到 27 | 编辑区，13 行文字，紧接菜单栏 | 蓝底白字 |
| 28、29 | DOS 状态栏，程序不动 | |

要点：

- 文字经名称表 0 显示。每个字符占 4 个图块号（一行 32 列共 `$80`），汉字占两列。图块布局：菜单栏 `$0100`，编辑区 `$0180` 到 `$07FF`（每行 `$80`），弹出区 `$0800` 到 `$0AFF`（只在弹出区打开期间使用）。
- 单元值的高 4 位里，位 15、14 选调色板组。程序用第 2 组（白底黑字，菜单栏与弹出区）和第 3 组（蓝底白字，编辑区），选中的菜单项用第 1 组；DOS 自己用第 0、1 组，所以状态栏颜色不变。调色板写在第 32 到 63 项。
- 光标是一个反白格：把所在单元改用第 2 组调色板，取消时改回第 3 组。
- 程序结束或运行其他程序之前调用 `screen_clear_all`：先把启动时保存的 DOS 控制台单元写回以释放窗口号，再像 DOS 的 `cls` 一样把控制台单元都写成空白图块（`$0080`）；之后 DOS 输出每一行时会自己分配字模槽。不能留着旧单元不管，否则 DOS 没有输出到的行会引用别的行正在用的字模槽，显示出半行重影。

## 5. 绘制策略

画一个字符要约 1/3 到 1/2 帧，整屏重画会明显卡顿，所以只画变化的部分。

- `view_refresh` 每次按键后执行：算出 13 行该显示的文字（`wanted_rows`），与屏幕上正显示的文字（`shown_rows`）比较。
- 只有一两行不同：直接重画这些行，并且只从第一个不同的字符画起。
- 不同的行较多：先判断是不是从某一行起整体下移或上移了一行（回车、删除换行、光标滚动）。是的话用 `screen_shift_lines_down`、`screen_shift_lines_up` 搬动单元，只重画新出现的行。
- 编辑区每一行有自己的一组字模图块（槽，`line_slot`）。整行上下移动时只搬单元、不重画字模，槽跟着行走，所以重画某一行必须用这一行当前的槽。
- 屏幕被弹出区或其他程序弄乱之后，调用 `view_invalidate`，下一次刷新整体重画。
- 光标位置和菜单栏右侧的状态区也按同样的方式只重画变化的字符。

水平方向：行比屏幕宽时按 `scroll_column` 水平滚动，光标列超出范围时自动调整。

## 6. 文本缓冲

`text-buffer` 是分块缓冲：

- 每块是一个扩展 RAM 页（4096 字节），块表记录每块所在的页号和已用字节数，块的先后顺序就是文档的先后顺序，页不要求连续。
- 插入和删除只移动所在块内的字节，每次经 256 字节的中转区搬运。
- 块写满后从 2048 字节处拆成两块，新块放进新申请的页；块被删空后释放页并从块表移除。
- 最多 120 块（`BUFFER_MAX_BLOCKS`），文档最大约 480 KiB，同时受空闲页数限制；内存不足时插入返回错误，界面在菜单栏右侧提示“内存不足”。
- 位置一律用文档里的字节序号，光标和屏幕首行也是；行号和列号随移动增减，只有跳到文档末尾时才统计换行符。

## 7. 文件读写

- 装入（`file_load`）：先用 `sb_file_load` 一次把整个文件读入连续的页，再每次取 256 字节，转成内部格式后追加到缓冲，最后释放这些页。CR LF 去掉 CR 并记下“文件用 CR LF”的标记，孤立的 CR 原样保留。`sb_file_read` 每次调用都要重读扇区，小段反复读很慢（2.4 KB 的文件曾要约 13 秒），所以只在连续空闲页不够装下整个文件时才退回每次 `sb_file_read` 读 256 字节的办法（`load_in_pieces`）。
- 保存（`file_save`）：DOS 只支持整块写盘，所以先申请能放下整个输出的连续页，转换后整体写出再释放。原文件用 CR LF（或新文件，默认 CR LF）时，每个换行写成 CR LF。
- 文件不存在时按新文件处理，文件名带上，保存时创建。
- 文件名输入允许大写字母、数字和 `. _ - \ : $ ~ ! # % & ( ) @`，小写自动转大写，最长 22 个字符；路径缓冲 `PATH_SIZE` 为 29 字节。

## 8. 按键

| 按键 | 功能 |
| --- | --- |
| F1 | 弹出文件菜单 |
| F5 | 保存并调用 `ASM.EXE` 汇编 |
| F8 | 关于 |
| Esc | 退出；有未保存的修改时询问是否放弃（按 Y 确认） |
| Ctrl+S | 保存 |
| 方向键、Home、End | 移动光标 |
| PgUp、PgDn | 上下移动 12 行 |
| Ctrl+Home、Ctrl+End | 到文档开头、末尾 |
| Delete、Backspace | 删除光标处、光标前的字符（汉字删两个字节） |
| Enter | 换行 |
| Tab | 插入空格，补到下一个 4 的倍数列 |
| 可见 ASCII 字符、输入法选出的汉字 | 插入 |

文件菜单里，上下键移动，回车或数字键 1 到 5 选择，F5、F8 直接选中汇编与关于，Esc 或 F1 关闭。菜单第一行显示文件名（没有名字时为“未命名”）和保存状态（“已保存”或“未保存”），不是菜单项。

编辑区用 `sb_ime_key_wait`（`$6D/$0A`）读键，让 DOS 已加载的中文输入法处理按键（Alt+F2 等切换输入法由系统处理）。返回的结果标志位 7 为 0 时，`output` 里是输入法产生的字节（汉字为两个字节），依次插入文档；位 7 为 1 时按键原样传回，`output[0]` 是 ASCII 码，`output[1]` 是扫描码；方向键、功能键的 ASCII 码为 0，用扫描码区分。带 Ctrl 的 Home、End 被换成另一组扫描码（`$77`、`$75`）。

菜单、对话框和汇编器直接读键盘，所以进入前调用 `sb_ime_suspend` 暂停输入法（状态行清空），结束后调用 `sb_ime_resume` 恢复；进入前用户已经自己暂停的，不替他恢复。输入法的候选字条画在 DOS 状态栏（第 28、29 单元行），不占用编辑区。

显示时：制表符显示为空格；两个字节都不小于 `$A1` 的相邻字节对当作一个 GB2312 汉字显示，占两列；其余不可显示的字符（含水平滚动时被截断的半个汉字、一行最后一列放不下的汉字）显示为 `.`。键盘直接输入的只有 `$20` 到 `$7E` 的字符，汉字经中文输入法输入。

汉字的两个字节仍按两列计，列号与水平滚动以字节为单位。`text-buffer.c` 的 `buffer_han_run` 向前统计指定位置之前连续的 `$A1` 以上字节数，奇数说明位置落在汉字中间，偶数说明在字符边界。`view.c` 用它判断水平滚动的起点是否落在汉字中间；`editor.c` 用它让左右移动、退格、Delete 一次越过或删除整个汉字，上下移动后光标落在汉字中间时退到汉字的第一个字节。局部重画时 `screen.c` 的 `align_to_character` 把起点退到汉字的第一个字节。

## 9. F5 汇编流程

`assemble_document` 的步骤：

1. 文件没有名字或有未保存的修改时先保存（没有名字会询问文件名）；保存失败就停止。
2. 把文件名写进命令行区 `SB_CMD_TAIL`（第 1 个字节是空格，后面是文件名）。
3. `screen_clear_all` 恢复 DOS 控制台并清空文字区，再显示“加载汇编器...”，让加载 `ASM.EXE` 的等待期间屏幕上有提示。
4. 文字输出库要求程序的起始页号是 4 的倍数：先试分配一页看下一个空闲页在哪里，不齐就把到下一个 4 的倍数之前的页占住，运行结束后释放。
5. `sb_exec("ASM.EXE")` 运行汇编器；汇编器显示“汇编中...”与结果并等待按键。
6. 清键盘缓冲，`screen_init` 重建界面，`view_invalidate` 让编辑区整体重画。找不到 `ASM.EXE` 时弹出提示。

`ASM.EXE` 在当前磁盘上查找，所以两个程序要放在同一张磁盘上。

## 10. 已知限制

- 保存需要连续的空闲页，大文件在页比较碎时可能保存失败，提示“保存文件出错”。装入和编辑不受影响。
- 汇编出错后编辑器不会自动跳到出错行，需要按汇编器显示的行号自己找。
- 汉字只认“两个字节都不小于 `$A1`”的字节对；其他非 ASCII 字节显示为 `.`，保存时都原样写回。
- 输入法的状态行与候选字条画在 DOS 状态栏，菜单、对话框和汇编期间输入法暂停。
- 没有查找、替换、撤销、复制粘贴。

## 11. 验证方法

仓库里没有自动化测试，修改后用模拟器验证：

1. `npm run build` 生成 `EDIT.EXE`，再构建 `../asm` 得到 `ASM.EXE`。
2. 用 fcdev 的调试服务启动模拟器（`fcdev run --debug --port 端口`），把两个 EXE 和测试文件做成软盘镜像挂载，在 DOS 里运行 `EDIT 文件名`。
3. 用调试服务发送按键，截图核对界面；改动文件内容后保存，读回软盘镜像里的文件，和预期逐字节比较。
4. 回归用例：约 27 KB 的大文件，在开头、中间、末尾插入、删除、合并行，保存后逐字节比较；F5 汇编后确认生成 EXE。
