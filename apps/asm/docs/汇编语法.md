# ASM 汇编语法

`ASM.EXE` 把 6502 汇编源文件汇编成 SB-DOS 的 EXE。本文说明源文件的写法、伪指令、程序布局、限制和错误信息。构建与使用见 [../README.md](../README.md)，内部实现见 [开发文档.md](开发文档.md)。

## 1. 源文件格式

- 文本文件，每行一条语句，换行用 CR LF 或 LF 都可以；代码部分每行最多 127 个字符，分号之后的注释长度不限。
- 一行的结构：`[标签:] [助记符 [操作数]] [; 注释]`，各部分之间用空格或制表符分隔。
- 分号后面到行尾是注释；写在双引号字符串里的分号不算注释。
- 助记符、伪指令、标签和常量名不区分大小写，汇编器一律转成大写；`.ascii` 字符串里的内容保持原样。
- 空行和只有注释的行会被忽略。

## 2. 数字与表达式

- 数字：十进制（`100`）或 `$` 开头的十六进制（`$64`），范围 0 到 65535；不支持二进制和字符常量。
- 表达式只有一种形式：`[<|>]项[+数字|-数字]`。

| 部分 | 说明 |
| --- | --- |
| 项 | 数字，或已定义的标签、常量 |
| `<` | 取值的低 8 位 |
| `>` | 取值的高 8 位 |
| `+数字`、`-数字` | 加减一个数字偏移，结果必须在 0 到 65535 之间；偏移只能是数字，不能是符号 |

```asm
        LDA #<TABLE       ; 取标签的低字节
        LDA #>TABLE       ; 取标签的高字节
        LDA TABLE+2       ; 标签加偏移
```

## 3. 标签与常量

- 标签：`名字:`，冒号必须写，后面可以接指令，也可以单独占一行。标签的值是当前位置的地址，可以在定义之前引用。
- 常量：`名字 = 值`，等号两边可以有空格。值必须是数字或已经定义的符号。
- 名字最长 31 个字符，常量名只能用字母、数字和下划线；标签和常量共用一张符号表，最多 1024 个，不能重名。
- 常量可以先使用后定义。值依赖标签的常量（如 `LO = <LABEL`）要写在使用它的指令之前，否则报“标签地址前后不一致”。

```asm
VALUE = $01
START:  LDA #VALUE
        STA $6000
```

## 4. 指令与寻址方式

只支持官方 6502 指令，不支持非官方操作码。

| 寻址方式 | 写法 | 字节数 |
| --- | --- | --- |
| 隐含 | `INX` | 1 |
| 累加器 | `ASL A` 或 `ASL`（适用于 `ASL`、`LSR`、`ROL`、`ROR`） | 1 |
| 立即 | `LDA #$10`、`LDA #<LABEL` | 2 |
| 零页 | `LDA $10` | 2 |
| 零页 X、Y | `LDA $10,X`、`LDX $10,Y` | 2 |
| 绝对 | `LDA $1234`、`JMP LABEL` | 3 |
| 绝对 X、Y | `LDA $1234,X`、`LDA LABEL,Y` | 3 |
| 间接 | `JMP ($1234)` | 3 |
| 先变址间接 | `LDA ($10,X)` | 2 |
| 间接后变址 | `LDA ($10),Y` | 2 |
| 相对 | `BNE LOOP` | 2 |

规则：

- 零页与绝对的选择：操作数是数字或已定义的常量，并且值不超过 `$FF` 时用零页，其余（包括所有标签）用绝对。`LDA $0010` 也按零页处理。
- 立即数的值不能超过 `$FF`。
- 条件分支的目标必须是同一银行里的标签，偏移不能超出 -128 到 127。
- `BRK` 单独写时补一个 `$00` 字节，共 2 个字节；也可以写 `BRK #n`。
- 指令没有零页形式时（如 `JMP $10`、`LDA $10,Y`、`STA $10,Y`）自动改用绝对形式，占 3 个字节。
- 指令没有对应寻址形式时报“指令不支持此寻址方式”，例如 `STA #$10`。

## 5. 伪指令

| 伪指令 | 写法 | 说明 |
| --- | --- | --- |
| `.org` | `.org 地址` | 设定当前银行的位置计数器，地址不超过 `$FFFF` |
| `.bank` | `.bank n` | 切换到第 n 个银行，n 为 0 到 113，0 是常驻区；各银行有自己的位置计数器，可以来回切换 |
| `.byte` | `.byte 表达式, ...` | 输出字节，每项不超过 `$FF` |
| `.word` | `.word 表达式, ...` | 输出 16 位小端字 |
| `.ascii` | `.ascii "文字"` | 输出字符串，不自动加结尾的 0 |
| `.bankcall` | `.bankcall n, 标签` | 调用第 n 个银行里的标签，调用后自动回到原银行 |
| `.include` | `.include "文件名"` | 把另一个文件的内容当作写在这里一样汇编，常用来引入符号文件 |

`.ascii` 支持的转义：`\n`（10）、`\r`（13）、`\0`（0）、`\xHH`（十六进制字节）、`\\`、`\"`。

`.bankcall` 的规则：

- n 为 1 到 113，标签必须定义在第 n 个银行里，可以在 `.bankcall` 之后才定义。
- 每条 `.bankcall` 展开成 24 字节的代码；常驻区末尾另有 101 字节的调用运行时代码，汇编器自动放置。
- A 和 X 会传给目标并带回调用者；Y 和标志位不保证保留。
- 目标代码以 `RTS` 结束。

`.include` 的规则：

- 文件名写在双引号里，最长 28 个字符，不分大小写，按当前目录查找（和源文件一样）。
- 被包含的文件按原位置展开，可以放常量、标签、指令和数据。常量定义写在包含文件里时，也可以在 `.include` 之前使用，汇编前会先扫描一遍收集常量。
- 最多嵌套 4 层，同时最多装入 8 个不同的文件（含主文件）；同一个文件被包含多次只读一次盘。
- 出错发生在包含文件里时，错误信息前先显示该文件的名字，行号是文件内的行号。
- `标签: .include "文件"` 这种带标签的写法，汇编前的扫描不会进入该文件，所以那个文件里的常量要先于使用它们的地方定义。

## 6. 程序布局

| 项 | 内容 |
| --- | --- |
| 文件头 | 前 8 个字节由汇编器生成：`4C 08 80 AA 55 00 00 00`，即 `JMP $8008` 加签名 |
| 入口 | `$8008`，程序从第一条常驻代码开始运行，用 `RTS` 返回 DOS |
| 常驻区 | 从 `$8008` 起，代码最多到 `$9F6F`；代码之后紧跟 128 字节的保留区，放跨银行调用的运行时代码，没有用 `.bankcall` 时也要留出 |
| 运行时变量 | `$9FF0` 到 `$9FF5`，供跨银行调用使用，程序不要写这些地址 |
| 银行 | 每个银行占 `$A000` 到 `$AFFF`，共 4 KiB，银行内的标签地址从 `$A000` 起算 |

输出文件大小为 `(最大银行号 + 3) × 4096` 字节，最小 16384 字节。文件里的页顺序是：第 0、1 页为常驻区，第 2 页为银行 1，第 3 页为栈页（空），银行 n（n≥2）在第 n+2 页。

## 7. 限制

- 代码部分每行最多 127 个字符（注释不计），名字最长 31 个字符，符号表最多 1024 项。
- 不支持宏、条件汇编和算术表达式（只有一个偏移）。
- `.include` 最多嵌套 4 层，同时最多装入 8 个不同的文件（含主文件）。
- 最多 113 个银行，整个映像最大约 464 KiB；实际能否生成取决于 DOS 里能申请到多少连续的扩展 RAM 页。
- 源文件、包含文件、符号表（10 页）和输出映像都放在扩展 RAM，要同时放得下。
- 速度：符号文件 SB2000.INC（约 31 KB、350 多个符号）在模拟器里约需 1000 帧（十几秒）汇编完，大部分时间花在读入和登记常量上。

## 8. 错误信息

汇编出错时显示“第 N 行出错”和一行原因；错误出在包含文件里时，先显示该文件的名字。原因用中文，汉字占 2 列，一行最多 31 列。

| 信息 | 原因 |
| --- | --- |
| 无法读取源文件 | 源文件打不开或读取失败 |
| 源文件是空的 | 源文件为空 |
| 一行超过127个字符 | 一行超过 127 个字符 |
| 符号表内存不足 | 申请不到符号表需要的页 |
| 连续内存页不足 | 申请不到输出映像需要的连续页 |
| 常量名无效、常量名含非法字符 | 常量名为空或含字母、数字、下划线以外的字符 |
| 名字超过31个字符、标签超过31个字符 | 常量名或标签名超过 31 个字符 |
| 常量缺少值 | `=` 后面没有值 |
| 常量的值必须已知 | 常量的值不是数字，也不是已定义的符号 |
| 符号重复定义 | 符号重复定义，标签与常量同名也算 |
| 标签地址前后不一致 | 标签地址与第一遍算出的不同，通常是值依赖标签的常量在定义之前被使用 |
| 符号超过1024个 | 符号超过 1024 个 |
| 指令名太长、操作数太长 | 助记符或操作数过长 |
| 寻址方式无效 | 操作数写法不属于任何寻址方式 |
| 指令不支持此寻址方式 | 该指令没有这种寻址方式 |
| 指令操作数无效 | 取不出指令的操作数表达式 |
| 符号未定义或值错误 | 符号未定义，或表达式不合法、超出范围 |
| 8位操作数超出范围 | 需要 8 位的操作数超过 `$FF` |
| 分支不能跨银行 | 分支目标不在同一银行 |
| 分支偏移超出范围 | 分支偏移超出 -128 到 127 |
| 数据缺少操作数 | `.byte`、`.word` 后面没有内容 |
| 数据表达式错误或超范围、数据表达式太长 | `.byte`、`.word` 的表达式不合法、超出范围或过长 |
| .ascii 字符串无效 | 字符串缺引号或转义不合法 |
| 伪指令缺少操作数 | `.org`、`.bank` 后面没有内容 |
| .org 地址无效 | `.org` 的地址不合法 |
| .bank 须为0到113、.bank 无效 | `.bank` 的编号超出范围或不合法 |
| 常驻代码超过$9FF0、银行超过4KB | 常驻区或银行放不下 |
| 没有空间放跨银行代码 | 常驻代码超过 `$9F6F`，没有地方放运行时代码 |
| .bankcall 写法：银行,标签 | `.bankcall` 缺少逗号 |
| .bankcall 银行号无效、.bankcall 银行号为1到113 | 银行号不合法或不在 1 到 113 之间 |
| .bankcall 标签太长 | 标签名过长 |
| .bankcall 标签不在该银行 | 标签不存在，或不在指定的银行里 |
| 找不到指令机器码 | 指令表里没有该助记符与寻址方式的组合 |
| 无法初始化输出映像、无法写入DOS文件头、无法初始化银行变量、无法写入机器码 | 写输出映像失败，通常是内存页出了问题 |
| 无法保存EXE文件 | 保存输出文件失败 |
| .include 文件名无效 | `.include` 后面不是用双引号括起来的 1 到 28 个字符的文件名 |
| 无法读取包含文件 | 包含文件不存在或读取失败 |
| 包含文件嵌套太深 | `.include` 嵌套超过 4 层（包括文件包含自己） |
| 包含的文件太多 | 同时装入的不同文件超过 8 个 |

## 9. 完整示例

```asm
VALUE = $12                 ; 常量
START:
        LDA #VALUE          ; 立即寻址
        STA $6000           ; 绝对寻址
        LDX #$00
LOOP:   INX
        CPX #$05
        BNE LOOP            ; 相对寻址，目标在同一银行
        .bankcall 2, WORK   ; 调用银行 2 里的 WORK
        RTS

TABLE:  .word START, LOOP
MSG:    .ascii "HI\0"

.bank 2
WORK:
        LDA #$77
        RTS
```

## 10. 调用系统接口

SB-DOS 的系统接口在汇编里都能调用：写功能号到 `$063E`（有子功能的再写 `$063F`），然后 `JSR $FFF0`；控制台输出等运行库例程经功能 `$25` 调用 ROM 里的例程。

符号文件 [../examples/SB2000.INC](../examples/SB2000.INC) 定义了系统调用用到的地址、功能号和运行库入口（350 多个符号），在源文件开头引入即可：

```asm
        .include "SB2000.INC"
```

说明：

- 该文件复制自 fcdev 的 `targets/sb2000/asminc/sb2000.inc`（项目的 `node_modules/fcdev` 里），fcdev 升级后需要重新复制。它只有“名字 = 值”的行，不占程序空间。
- 汇编时它要和源文件在同一个目录（同一张磁盘）里，约 31 KB，读入和登记符号需要十几秒。
- 值不超过 `$FF` 的符号按零页寻址；`$FFF0`、`$063E` 这类大于 `$FF` 的按绝对寻址。

完整的可运行例子见 [../examples/hello.asm](../examples/hello.asm)：在控制台输出“你好，小霸王！”，文字用 GB2312 字节写进 `.ascii`。程序返回 DOS 时 DOS 会清屏，所以示例在返回前先等待按键。
