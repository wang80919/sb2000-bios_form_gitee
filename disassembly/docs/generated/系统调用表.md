# 系统调用表

入口是 `JSR $FFF0`（`$FFF0` 是 `JMP $FD8E`）。调用前把功能号写入 `$063E`，子功能与参数放在 `$063F` 起的参数区和 A、X、Y 中；
分发器在 `$FD8E-$FEFC`，规则见 `tools/dispatch-map.mjs`，并由 `tools/verify-dispatch.mjs` 用模拟器实测核对。
本表由 `tools/render-api-doc.mjs` 生成，说明来自 `tools/symbols.mjs`；没有说明的功能尚未阅读，且不含指向“未实现”桩例程 `$E150` 的功能号。

## 内核里的辅助入口

| 地址 | 符号 | 说明 |
| --- | --- | --- |
| $C000 | RESET | 复位入口 |
| $C084 | NMI_HANDLER | NMI 中断入口 |
| $C12B | IRQ_HANDLER | IRQ 中断入口 |
| $FD8E | SYSCALL_DISPATCH | 系统调用分发器，按 $063E 功能号分流，保存并恢复 P、A、X、Y 与 $0639-$063C |
| $FF16 | CALL_VECTOR_10 | JMP ($0010)，分发器用它进入处理例程 |
| $FEFC | SYSCALL_RETURN | 分发器收尾：恢复窗口页号与寄存器后 RTS |
| $ED94 | MAP_WINDOWS_8000 | 把 A 起连续 4 个页映射到 $8000-$BFFF（写 $4040-$4043 并同步影子 $0639-$063C） |
| $EDB4 | RESTORE_WINDOWS_8000 | 按影子 $0639-$063C 重写 $4040-$4043 |
| $EC61 | FAR_READ_BYTE | 读远字节：页号 $0641、偏移取自 $14/$15，Y 为索引，结果在 A（$FFF3 入口） |
| $EC8A | FAR_WRITE_BYTE | 写远字节：参数同 FAR_READ_BYTE，A 为写入值（$FFF6 入口） |
| $ECB3 | FAR_COPY_IN | 从页组 $0642 的 ($0C) 复制 $064F 字节到 $0700+X（$FFEA 入口） |
| $ECEE | FAR_COPY_OUT | 从 $0700+X 复制 $064F 字节到页组 $0642 的 ($0C)（$FFED 入口） |
| $EE76 | INLINE_JUMP_TABLE | 内联跳转表：JSR 之后紧跟若干 2 字节地址，A 为下标，直接跳到表项，不会返回到 JSR 的下一条指令 |
